# Mr. Mak Workspace 0.6.0

Workspace cards can now be edited directly. Choose **+ New card**, pick Gallery
or Research, then add images, Markdown notes, source links, prompts and statuses.
Reorder entries with drag and drop or arrow buttons. Preview the page and save
when it is ready.

The content lives in one `.card.json` file with images beside it. Agents can edit
that same file without reading or rewriting the page layout. Existing HTML
reports, Markdown documents and custom project pages continue to work.

The editor keeps unfinished drafts when you switch cards in the same window,
checks for changes on disk before saving, and keeps a local copy of the previous
saved version. A conflict leaves your draft available to review or download.

Gallery and Research use the same format, so you can change views without losing
content. Phone access and browser preview can read the cards and enlarge their
images. Content editing is available in the desktop Workspace.

The starter includes editable tabs in My Dream Game and Creative MCP Connections.
The Workspace authoring skill, Help and README explain the shared format.

This update also includes the Windows screen-cache saving fix from main:
temporary file locks are retried, unchanged screens are skipped, and one failed
snapshot does not prevent other chats from saving.

On phones, the report page menu stays above embedded pages and inside the
screen edges. Switching between HTML and Markdown tabs works with clicks and taps.

The separate skills ZIP includes all 20 workflows, complete Codex and Claude
copies, and the editable-card guide and validator.
