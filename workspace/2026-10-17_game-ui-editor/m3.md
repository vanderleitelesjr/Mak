## Delivered behavior

1. **Versioned behavior document:** states, typed variables, data bindings,
   conditions, event rules and effects. M2 visual documents open through an
   in-memory migration; the first save preserves an original-format backup.
   Invalid references/types and unsupported future versions are refused.
2. **Bounded evaluator:** one TypeScript implementation for desktop preview and
   a matching presentation-layer C# evaluator. Shared JSON fixtures agree
   on values, event ordering, transitions and execution limits. Gameplay rules
   and deterministic simulation are not changed.
3. **Authoring interface:** selected element/component bindings and an explicit
   event → conditions → effects editor. Semantic intent remains editable when a
   real mapping is missing; unresolved required actions are visibly reported.
4. **Meaningful preview:** simulated resources, selection, commands, queues and
   progress; repeated/contextual components; tooltips; and start/play/pause/end
   transitions. Preview state stays outside the authored project document.
5. **Native catalog and verification:** the isolated GE presentation adapter
   exposes real data/action paths, with parity and native session checks.
   Browser/Windows tests cover saved behavior, representative preview
   scenarios, disabled actions and migration/recovery. Full screen integration
   remains M5.
