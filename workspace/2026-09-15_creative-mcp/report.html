Creative MCP Connections

A practical shortlist for 3D, image and game workflows. Nothing in this list is automatically installed.

Connect only what your task needs

The starter repository has no active MCP configuration. This shortlist shows useful places to begin. A skill is an instruction file; a connection gives an agent tools. Installing one does not install the other.

Where the shortlist came from

Adapted from the tool list in Stefan Vaskevich's published 3D setup article, with the hosted fal.ai option added. The links above go directly to the corresponding projects or providers. This sample does not contain private account configuration.

Check your own machine

  1. Open the MCP rail and inspect project versus global configuration.
  2. Pick the editor or provider needed for the current task.
  3. Read its current installation instructions and configure it in this project where supported.
  4. Start the editor or authenticate with your own account.
  5. Run a read-only connection check, such as listing the current scene or available model schemas.
  6. Read the relevant skill before asking for a paid generation or a scene edit.
